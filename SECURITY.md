# Security policy

birkez is a security tool, so security reports are very welcome.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, report privately through GitHub:

1. Go to the [Security tab](https://github.com/yusufiyilmaz/birkez/security) of this repository.
2. Click **Report a vulnerability**.

Please include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible, and credit in the fix if you'd like.

## Scope

In scope: anything that lets someone read a note they shouldn't, read a note more than once, burn someone else's note without the full link, learn the key or password, or bypass the security headers or rate limits.

Out of scope: the limitations already documented in the README's "Known limitations" section (for example, a compromised server serving modified JavaScript).
